Link to exe in sidebar. Build the project yourself by:
1) Ensuring you're in the axolotlmeasurement directory
2) Run setup-python-runtime, using .sh or .ps1 depending on operating system
3) Running npm run build:win or build:mac, depending on operating system.

Most of this was written by hand, Claude Code was used towards the end of the project to help build & export the app, as well as for some misc features. Code authorship should reflect this.
